Agenda integrada — em breve

A conexão em tempo real com Google Agenda e Outlook fica para uma próxima etapa, como combinamos. Ela precisa de um cadastro de aplicativo OAuth no Google Cloud Console e no Azure Portal, além de o painel ficar publicado num endereço fixo (por exemplo, GitHub Pages) — logins do Google e da Microsoft não funcionam de forma confiável quando a página é aberta como um arquivo local.

  • 1. Publicar este painel em um endereço fixo (posso ajudar a colocar no GitHub Pages ou similar).
  • 2. Criar um app OAuth gratuito no Google Cloud Console (para o Google Agenda).
  • 3. Criar um registro de app no Azure Portal (para o Outlook / Microsoft 365).
  • 4. Eu adiciono os botões de login e a lista de compromissos aqui nesta aba.
